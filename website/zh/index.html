01用例

为创作者而做，不是演示。

从基础模型出发，重复一套配方，而不是手工重做每个变体。

◈

VRChat 世界

用基础模型批量生成 NPC 或头像变体：预设、头发、颜色和服装各不相同。

▧

视觉小说 / 叙事游戏

从角色清单构建统一阵容：脸、头发、服装和配色，然后导出 VRM。

✦

素材包 / Booth

用可重复的配方制作角色或服装系列，而不是逐个重做。

02批处理示例

一套配方，多个变体。

批处理就是一套配方：选择基础、应用预设、修改贴图/材质，然后导出。请替换成自己的 ID 和路径。

vroid_batch
vroid_batch operations=[
  {"tool":"vroid_apply_preset","args":{"id":"<preset-id>"}},
  {"tool":"vroid_colorize","args":{"group":"<group-id>","r":0.72,"g":0.42,"b":0.35}},
  {"tool":"vroid_export_vrm","args":{"path":"D:\\out\\npc_01.vrm","delete_transparent":true}}
]

  1. 选择基础

    打开 VRoid 模型，确定要变化的部位。

  2. 应用配方

    预设、颜色、贴图、体型或相机。

  3. 导出系列

    每个变体一个 VRM，使用统一命名。

示例配方，不是固定预设；结果取决于模型和 VRoid 版本。

04工作原理

通往 VRoid 的本地桥接。

MCP 调用会变成 VRoid 命令，支持撤销、贴图、预设、相机和 VRM 导出；不直接改写文件，也不依赖云服务。

05功能

可以做什么。

◈

参数与导航

按分区/类别选择面部、身体和服装，用类型化的 vroid_set_param 调整。

▧

贴图与图层

导出/重新导入 PNG、改色，并保留透明区域与明暗。

✦

头发、预设与缓存

头发颜色、程序化发束、预设搜索和共享缩略图缓存。

⇩

VRM 导出

通过 VRoid 原生导出 VRM 1.0/0.x，支持透明网格删除、多边形/材质/骨骼精简。

▣

最小化/后台运行

VRoid 最小化时仍可编辑、截图和导出；后台模式始终开启。

↶

安全操作

所有改动进入 VRoid 历史，可用 Ctrl+Z 撤销；保存前可检查状态。

08安装

三步安装

只需 Windows 与 VRoid Studio 2.16。NSIS 安装器会安装 BepInEx 6，并内置 Python 3.12、numpy、Pillow、插件和 MCP 服务器。

  1. 关闭 VRoid 和 Claude

    完全退出 VRoid Studio 和 Claude Desktop。

  2. 运行安装器

    运行 VRoidMcp-Setup-v<version>.exe。支持四种语言，无需管理员权限；可选择 Claude Code / Desktop、DeepSeek Harness 或重新安装 BepInEx。

  3. 先启动 VRoid，再重启客户端

    BepInEx 首次启动会多花 1–2 分钟。然后重启 Claude Code / Desktop 或 DeepSeek Harness，并调用 vroid_status。

环境要求

  • Windows 10 / 11
  • VRoid Studio 2.16（Steam）
  • 无需 Python — 已内置 3.12、numpy、Pillow
  • BepInEx 6 由安装器安装

0.12 新功能： 标准 Windows 安装器、内置 Python/numpy/Pillow、DeepSeek Harness 支持，以及 VRoid 2.16 稳定性。
