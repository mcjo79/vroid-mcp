01Cas d’usage

Pensé pour les créateurs, pas pour les démos.

Trois façons concrètes d’utiliser le pont. À chaque fois, on part d’un modèle de base et on répète une recette au lieu de tout refaire à la main.

◈

Mondes VRChat

Peupler un monde avec des PNJ ou des variantes d’avatar à partir d’un modèle de base — même recette, presets, cheveux, couleurs et tenues différents.

▧

Visual novels et jeux narratifs

Construire un casting cohérent depuis une liste de personnages : visages, cheveux, tenues et palettes, puis exporter les fichiers VRM.

✦

Packs d’assets / Booth

Produire des séries de personnages ou de tenues avec des recettes répétables, sans reconstruire chaque variante à la main.

02Exemple de batch

Une recette, plusieurs variantes.

Un batch est une recette : choisir une base, appliquer un preset, recolorer une texture ou un matériau, puis exporter. Remplacez les IDs et chemins par les vôtres.

vroid_batch
vroid_batch operations=[
  {"tool":"vroid_apply_preset","args":{"id":"<preset-id>"}},
  {"tool":"vroid_colorize","args":{"group":"<group-id>","r":0.72,"g":0.42,"b":0.35}},
  {"tool":"vroid_export_vrm","args":{"path":"D:\\out\\npc_01.vrm","delete_transparent":true}}
]

  1. Choisir une base

    Ouvrir un modèle VRoid et choisir les emplacements à faire varier.

  2. Appliquer la recette

    Presets, couleurs, textures, corps ou caméra.

  3. Exporter la série

    Un VRM par variante, avec le même modèle de nommage.

Recette d’exemple — pas un preset figé. Le résultat dépend du modèle et de la version de VRoid.

Ce que le test a appris

  • La couleur sous les cheveux se règle sur la calotte (Level1BaseHair_OverlayColor) et sur la texture du preset, après vroid_begin_hair_edit.
  • Un blazer preset peut être recoloré sélectivement : le beige devient vert forêt, la chemise blanche et les boutons dorés restent intacts.
  • Les vêtements par défaut doivent être retirés avec vroid_remove_item avant d'appliquer une tenue, sinon les couches se superposent.
  • Le pont ne change pas la pose : le modèle reste en T, comme dans VRoid. La caméra, elle, se règle avec vroid_camera.

04Comment ça marche

Une chaîne courte, locale, au cœur de VRoid.

Le serveur MCP ne manipule pas les fichiers de VRoid. Il traduit des appels MCP en commandes internes de VRoid, exactement comme le ferait l'interface : les changements apparaissent dans l'historique et se comportent comme des réglages manuels.

Client MCP Claude Code, Claude Desktop, DeepSeek, tout client MCP stdio
JSON-RPC→
Serveur MCP vroid_mcp.py — stdlib Python, zéro dépendance :7811
HTTP local→
Plugin BepInEx Injecté dans VRoid, écoute uniquement la boucle locale 127.0.0.1
commandes→
VRoid Studio VRoidCore.Editing.Context — modèle, calques, historique Ctrl+Z

Ce que ça change pour une IA

L'IA n'a plus à simuler des clics ni à capturer l'écran pour agir : elle lit les groupes, les curseurs et les calques, puis exécute des commandes typées. Elle peut enchaîner un preset, une recoloration de texture et une capture pour vérifier le résultat.

  • Lecture des groupes, paramètres, matériaux et calques.
  • Écriture via les commandes de VRoid, donc annulable et rejouable.
  • Captures d'écran et caméra pour contrôler visuellement chaque étape.
Claude Code
claude mcp add vroid -- python <chemin>\mcp_server\vroid_mcp.py
claude_desktop_config.json
{
  "mcpServers": {
    "vroid": {
      "command": "python",
      "args": ["<chemin>\\mcp_server\\vroid_mcp.py"]
    }
  }
}

05Fonctions

Tout ce que l'interface fait, une IA peut le demander.

Les outils couvrent le corps, le visage, les textures, les cheveux, les vêtements, les presets et la caméra — avec un cache partagé pour arrêter de tout réessayer.

Paramètres & silhouette

Curseurs de forme, os, couleurs, taille et poids cibles. Les curseurs appariés Mag/Shrink sont gérés côté serveur.

Textures & calques

Lister, exporter en PNG, retoucher, réimporter, recolorer ou ajouter un calque. La transparence et les plis sont conservés.

Cheveux

Matériaux, couleurs, longueur des groupes procéduraux, allongement et duplication des mèches dessinées au pinceau.

Presets

1 750 presets, 50 catégories, y compris les sous-parties (frange, cheveux arrière, lèvres, oreilles…). Appliquer, retirer, éditer.

Caméra & captures

Angles, zoom, pan, projection orthographique, vues prédéfinies, captures d'écran et aperçu d'expression.

Cache de presets

Un catalogue local partagé entre IA : vignettes, descriptions, tags et couleurs, synchronisé sans perdre les annotations.

08Installation

Trois étapes, un installeur.

Windows, VRoid Studio et Python 3.8+ (PATH). L'installeur s'occupe de BepInEx 6, du plugin, du serveur MCP et de la configuration de Claude.

  1. 1

    Télécharger la release

    Récupérez VRoidMcp-Setup-v<version>.exe depuis les releases GitHub.

  2. 2

    Fermer VRoid, lancer l'installeur

    Lancez le setup : un installeur Windows classique, sans droits administrateur ni console. Il trouve VRoid via Steam, installe BepInEx si besoin et copie le plugin.

  3. 3

    Redémarrer Claude

    Redémarrez Claude Code ou Claude Desktop : les outils vroid_* apparaissent dans la session.

Prérequis

  • Windows 10 / 11
  • VRoid Studio (Steam, Unity 6000.0.62)
  • Python 3.8 ou plus récent
  • numpy et Pillow conseillés pour les textures

Le premier lancement après BepInEx prend une à deux minutes de plus (génération de l'interop).

Télécharger la dernière release
Ce que fait exactement l'installeur
  • Cherche VRoid dans les bibliothèques Steam (sinon, choisissez son dossier avec « Parcourir… »).
  • Installe BepInEx 6.0.0-be.791 IL2CPP, vérifie l'empreinte SHA-256, et met de côté une version précédente.
  • Copie le plugin dans BepInEx\plugins\VRoidMcpBridge.
  • Copie le serveur, les outils et la documentation dans %LOCALAPPDATA%\VRoidMcp.
  • Déclare le serveur vroid dans Claude Code et Claude Desktop, avec sauvegarde préalable.
Pourquoi un plugin BepInEx ?

VRoid Studio est un jeu Unity IL2CPP. Le plugin s'exécute dans le processus de VRoid et accède directement à VRoidCore.Editing.Context : c'est ce qui permet de lire les paramètres et d'exécuter les vraies commandes d'édition, plutôt que de simuler des clics.

Sécurité et vie privée

Le serveur HTTP n'écoute que sur 127.0.0.1:7811. Aucune donnée n'est envoyée sur le réseau. Le serveur MCP est en stdio, sans dépendance Python. Toutes les modifications sont annulables dans VRoid.

09Coulisses

Les détails qui font la différence.

Un pont IL2CPP demande quelques précautions. Voici les pièges rencontrés et ce qui a été vérifié.

01

Le focus

VRoid suspend sa boucle quand sa fenêtre perd le focus. Le plugin force Application.runInBackground pour que les commandes restent fluides.

02

Les KeyValuePair

Construire des KeyValuePair<,> IL2CPP côté managé fait planter le runtime. Le pont passe par un Dictionary natif.

03

Les captures

ScreenCapture.CaptureScreenshot(string) plante dans l'interop. Le plugin utilise CaptureScreenshotAsTexture puis EncodeToPNG.

Limites assumées

Une mise à jour de VRoid Studio peut renommer les classes internes et casser le plugin. BepInEx 6 est en « bleeding edge » : stable ici, sans garantie. Les plugins BepInEx 5 (comme VRoidXYTool) ne sont pas compatibles avec cette installation IL2CPP.

Le pont expose ce que VRoid expose : certains réglages très spécifiques (ombres cuites, shaders) restent hors de portée. C'est aussi ce qui garantit des modifications propres et annulables.

10FAQ

Questions fréquentes.

Faut-il Claude pour l'utiliser ?

Non. Le serveur parle MCP en stdio : Claude Code et Claude Desktop sont configurés par l'installeur, mais tout client MCP compatible — DeepSeek inclus — peut lancer vroid_mcp.py et appeler les outils.

Est-ce que ça marche avec la dernière version de VRoid ?

Le pont est validé avec VRoid Studio 2.14.0 (Unity 6000.0.62). Une mise à jour peut renommer les classes internes ; dans ce cas, il faut refaire le dump et ajuster le plugin.

Les modifications sont-elles définitives ?

Non. Elles passent par l'historique de VRoid : Ctrl+Z les annule, et vroid_undo / vroid_redo sont exposés à l'IA. Le projet ouvert n'est pas sauvegardé automatiquement.

Est-ce que le pont envoie des données sur Internet ?

Non. Le plugin écoute sur la boucle locale (127.0.0.1:7811) et le serveur MCP communique en stdio avec le client. Aucune télémétrie n'est intégrée.

Puis-je l'utiliser pour autre chose que des personnages ?

Oui : les outils couvrent aussi les vêtements, les presets, les textures, les expressions et la caméra. Le cache de presets aide à choisir sans rouvrir VRoid à chaque essai.
