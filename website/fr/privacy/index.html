Politique de confidentialité

Comment ce site traite vos données. Dernière mise à jour : 28 octobre 2026.

Ce site présente le VRoid MCP Bridge, un pont local entre un client IA et VRoid Studio. C’est un site de documentation : il n’y a ni compte, ni paiement, ni formulaire d’envoi de fichiers.

Qui est responsable de vos données ?

Le site est publié par mcjo79, mainteneur du projet VRoid MCP Bridge, qui agit en qualité de responsable du traitement au sens de l’article 4.7 du RGPD. Pour toute question ou demande relative à vos données personnelles, contactez l’éditeur via le dépôt du projet : github.com/mcjo79/vroid-mcp. Si votre demande contient des informations sensibles, demandez d’abord un canal privé : les issues GitHub sont publiques.

Quelles données sont collectées ?

Google Analytics 4 est chargé avec tous les signaux de consentement en « refusé ». Dans cet état, il ne crée aucun cookie de mesure et ne stocke aucun identifiant sur votre appareil, mais Google peut recevoir une requête de mesure sans cookie. Rien n’est stocké pour la mesure avant votre accord.

Après votre accord, Google Analytics 4 collecte :

  • les pages consultées, la page d’origine et les liens cliqués ;
  • une localisation approximative déduite de votre adresse IP (pays, région ou ville) ;
  • des informations techniques : type d’appareil, système, navigateur, langue et taille d’écran ;
  • des événements d’interaction, comme la profondeur de défilement ou les clics sortants ;
  • un identifiant aléatoire stocké dans un cookie pour reconnaître un navigateur qui revient.

Le site ne demande ni nom, ni adresse e-mail, ni compte. Aucun modèle, aucune image et aucun fichier modifié dans VRoid Studio n’est envoyé à ce site. Selon Google, Google Analytics 4 ne journalise ni ne conserve les adresses IP individuelles : l’adresse IP sert à déduire la localisation approximative, puis est écartée.

Si vous refusez, analytics_storage reste refusé : aucun cookie de mesure n’est créé et aucun identifiant n’est conservé. Seuls votre choix et votre préférence de thème restent stockés localement dans votre navigateur.

Base légale et consentement

La mesure d’audience repose sur votre consentement (article 6.1.a du RGPD). Le consentement est recueilli par le bandeau, il est facultatif et n’est pas une condition d’accès au site. Il est conservé 180 jours ; au-delà, le bandeau vous interroge à nouveau. Vous pouvez le retirer à tout moment, aussi facilement que vous l’avez donné.

Les données de mesure sont traitées par Google Ireland Limited (Gordon House, Barrow Street, Dublin 4, Irlande) et Google LLC (1600 Amphitheatre Parkway, Mountain View, CA 94043, États-Unis), qui agissent comme sous-traitants selon les conditions de traitement des données de Google. Les transferts hors Espace économique européen s’appuient sur les clauses contractuelles types de la Commission européenne et/ou le cadre de protection des données UE–États-Unis, selon le cas. Voir la politique de confidentialité de Google et l’utilisation des données des sites partenaires.

Le site ne vend pas de données, ne diffuse pas de publicité et ne construit pas de profil utilisateur.

Hébergement

Le site est hébergé par GitHub Inc. (88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis) via GitHub Pages. Comme tout hébergeur, GitHub traite des données techniques de connexion (adresse IP, navigateur, page demandée) pour fournir le site et en assurer la sécurité, sur la base de son intérêt légitime à exploiter le service. Voir la déclaration de confidentialité de GitHub.

Combien de temps les données sont-elles conservées ?

Votre choix de consentement est conservé dans votre navigateur pendant 180 jours. Dans Google Analytics 4, la durée de conservation des données utilisateur est configurée dans la propriété Analytics (2 mois par défaut, jusqu’à 14 mois). Les rapports agrégés, qui n’identifient plus personne, peuvent être conservés plus longtemps.

Vos droits

Conformément au RGPD, vous disposez d’un droit d’accès, de rectification, d’effacement, de limitation, d’opposition, de portabilité et de retrait du consentement à tout moment. Pour exercer ces droits, contactez l’éditeur via le lien du dépôt ci-dessus.

Vous avez également le droit d’introduire une réclamation auprès d’une autorité de contrôle. En France, il s’agit de la CNIL ; ailleurs dans l’UE/EEE, contactez votre autorité nationale.

Stockage local

Deux valeurs sont stockées dans le localStorage de votre navigateur : vroid-theme (thème clair ou sombre) et vroid-consent-v1 (votre choix de mesure d’audience et sa date d’expiration). Elles sont strictement nécessaires au souvenir de vos préférences et ne sont jamais envoyées à un serveur.

Modifications

Cette politique peut être mise à jour lorsque le site change. La date en haut indique la dernière révision. Si un changement affecte votre consentement, le bandeau vous interrogera à nouveau.
